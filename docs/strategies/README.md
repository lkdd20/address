# 地址生成共用规则

适用于除中国外的全部国家和地区，中国另见 [CN 文档](CN-China-address-generation.md)。各国文档只记录本国差异；证据等级、许可、配额与 VPS 边界见 [数据源与自动同步方案](../data-sources.md)。规则变化时同步更新本文件、实现与测试。

## 同步

- 每个来源自动初始化一次；额度或 checkpoint 未完成的任务自动续跑，完整扫描或来源耗尽后停止，不按周期重复。只有上游版本、提取能力变化或管理员刷新才重跑；周期元数据探测默认关闭。
- 任务上限 150 分钟；导出进程上限 75 分钟（日本 ABR 90–95 分钟，超时先存断点）。超大 Geofabrik 整包按子区域分片（俄罗斯、英国、加拿大、美国、法国、德国）。
- 国家目标 5,000,000，各级采样上限不限；完成仍要求覆盖率与节点下限，修改目标不解除来源上限状态。
- 存储预算：软上限 55 GiB、硬上限 60 GiB，磁盘剩余低于 10 GiB 视同已满；单次新增不超过 50,000 条且不超过剩余空间的国家均分份额（每条按 12 KiB 估算）；被步长截断的成功运行 1 分钟后继续。
- 同步增长只计本次导入新增或恢复发布的行减去撤下的行；导入未提交时增长为 0。没有自身增长的成功同步按来源已达上限处理。
- 导入收尾只更新本次写入或被取代的地址（主证据、发布状态、数据集计数、生成索引），生成序号空洞超过 25% 时整国重排，热池统计在提交后重建。
- 某国已入库未发布的地址超过 20,000 条时暂缓该国新导入 30 分钟。
- 邮编：本地数字先转 ASCII，不符合本国格式的留空而不淘汰地址。推断（各国步骤见本国文档）只在结果唯一时填写并记录于 `address_postcode_inference`，来源后续提供邮编时以来源为准；整国扫描每个推断修订只执行一次，之后每次同步只检查本次导入的地址。
- 同步进程启动时只修复与发布池不一致的派生统计，不重抓来源、不重置断点或耗尽/额度状态。

## 地址门禁

- 接受真实街道级与门牌级地址，按实际精度标记，不编造缺失字段；无法唯一确定的邮编留空。
- 门牌：无门牌标记（S/N、snc、SIN VALOR、N/A、C/O 等）、不含数字或超过 30 字符的门牌只证明街道，降为街道级并清空门牌、楼名、单元与住宅证据（英国房屋名除外）。
- 城市：含逗号的城市取目录中存在的部分，前一段在区县为空时作区县；去掉国家名、行政区名和市镇类型词后仍无法确定的清空，再按坐标从目录补全，补不到则拒绝。缺城市时只在来源一级行政区内取最近城市。
- 街道：去掉末尾重复的城市、行政区、邮编或国家段；仍有三段以上的拒绝（巴西 Quadra/Lote 除外）。
- 一级行政区按 Overture 一级行政区多边形（ISO 3166-2）判定：距所有多边形超过约 2 km 的坐标视为境外并拒绝；目录层级与多边形一致的国家，来源区域与该多边形的名称、英文名、代码或目录名都不一致时改为多边形官方名称与代码。各国适用范围见本国文档。
- 本地语言组件中紧邻中日韩文字的“?”或 U+FFFD 视为编码损坏（`corrupted_text`），拒绝导入与发布。
- 行政目录本地名以 Wikidata 本国语言标签核验（核验表 `server/database/catalog-native-corrections.json`，由 `scripts/verify-catalog-native-names.mjs` 生成并人工复核省级），英语国家使用英文名；曾用错误本地名补全的已存地址在其所属省内一次性改写。
- 门禁变化后，sync 启动时按国家和修订一次性复检已存地址：不合格的以 `publication-validation:<修订>:<时间>` 撤下，与已有地址重复的删除；所需外部数据不可用时修订保持未完成，下次启动补做。

## 翻译与发布

- 导入默认延迟翻译；回填按缓存优先，再按管理员为每个凭据设定的优先级调用（同级轮询，跳过不可用、冷却、额度耗尽或失败的路由），DeepL 只经 Credential Broker 使用 Free Key 并按码点预留额度。限速、鉴权、额度等待不等于来源耗尽。
- 只翻译语义字段；门牌、单元、邮编、行政代码与数字标识必须保持不变，供应商改动数字时只翻译文本片段并还原标识。中文组件出现问句、俄文通名缺失或长原名只剩单字时视为不可用。
- 普通地址的中文道路名未译出时可先以原名发布并留在翻译队列；住宅地址须完整中文版本。
- 中文完整地址由中文组件直接相连，仅在两侧都是汉字、假名以外的字母或数字时加空格，且必须与中文组件一致。
- 每批最多发布一个国家，批次 180 秒硬超时；发布事务只锁待发布地址行，对变更地址执行完整来源、地址和语言门禁。失败按指数退避最多 3 次，之后须输入或配置变化才重评；仅缓存的复检独立运行，不消耗翻译请求。
- 被发布校验撤下的地址只由翻译恢复复检合格后重新发布，重新导入不恢复它们。

## 生成与筛选

- 生成索引只是候选加速；返回前每条地址按当前质量、有效期、国家、住宅证据和筛选条件复检。
- 未筛选按连续序号等概率选择，筛选使用有界索引窗口；不加载全池、不全表随机排序。未传 seed 时每次请求生成新 seed，相同 seed 在同一快照可复现。
- 筛选选项只展示有可用地址的节点，管理覆盖树保留官方目录的零地址节点；邮编以生成索引中的完整码为准。
- 覆盖以官方行政目录为分母，按目录 ID 区分同名节点，歧义保留未映射；每次国家快照发布后重建总量与住宅覆盖。
