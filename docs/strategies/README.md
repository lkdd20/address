# 地址生成共用规则

适用于除中国外的全部国家和地区，中国另见 [CN 文档](CN-China-address-generation.md)。各国文档只记录本国差异；证据等级、许可、配额与 VPS 边界见 [数据源与自动同步方案](../data-sources.md)。规则变化时同步更新本文件、实现与测试。

## 同步

- 每个来源自动初始化一次；额度或 checkpoint 未完成的任务自动续跑，完整扫描或来源耗尽后停止，不按周期重复。只有上游版本、提取能力变化或管理员刷新才重跑；周期元数据探测默认关闭。
- 任务上限 150 分钟；导出进程上限 75 分钟（日本 ABR 90–95 分钟，超时先存断点）。超大 Geofabrik 整包按子区域分片（俄罗斯、英国、加拿大、美国、法国、德国）。
- 国家目标 5,000,000，各级采样上限不限；完成仍要求覆盖率与节点下限，修改目标不解除来源上限状态。
- 存储预算：软上限 55 GiB、硬上限 60 GiB，磁盘剩余低于 10 GiB 视同已满；单次新增不超过 50,000 条且不超过剩余空间的国家均分份额（每条按 12 KiB 估算）；被步长截断的成功运行 1 分钟后继续。
- 同步增长只计本次导入新增或恢复发布的行减去撤下的行；导入未提交时增长为 0。没有自身增长的成功同步按来源已达上限处理。
- 导入收尾只更新本次写入或被取代的地址（主证据、发布状态、数据集计数、生成索引），生成序号空洞超过 25% 时整国重排，热池统计在提交后重建。
- 某国已入库未发布的地址超过 20,000 条时暂缓该国新导入 30 分钟。
- 邮编：本地数字先转 ASCII，不符合本国格式的留空而不淘汰地址。推断（各国步骤见本国文档）只在结果唯一时填写并记录于 `address_postcode_inference`，来源后续提供邮编时以来源为准；整国扫描每个推断修订只执行一次，之后每次同步只检查本次导入的地址。
- 同步进程启动时只修复与发布池不一致的派生统计，不重抓来源、不重置断点或耗尽/额度状态。

## 地址门禁

- 接受真实街道级与门牌级地址，按实际精度标记，不编造缺失字段；无法唯一确定的邮编留空。
- 门牌：无门牌标记（S/N、snc、SIN VALOR、N/A、C/O 等）、不含数字或超过 30 字符的门牌只证明街道，降为街道级并清空门牌、楼名、单元与住宅证据（英国房屋名除外）。
- 城市：含逗号的城市取目录中存在的部分，前一段在区县为空时作区县；去掉国家名、行政区名和市镇类型词后仍无法确定的清空，再按坐标从目录补全，补不到则拒绝。缺城市时只在来源一级行政区内取最近城市。
- 城市字段为一级行政区代码（如 `VI`、`NY`、`BC`）、纯数字、邮编或泰国“ตำบล/อำเภอ/จังหวัด”拼接整段时视为没有城市（`invalid_locality`），清空后按坐标从目录补全，补不到则拒绝。
- 街道：去掉末尾重复的城市、行政区、邮编或国家段；仍有三段以上的拒绝（巴西 Quadra/Lote 除外）。
- 一级行政区按 Overture 一级行政区多边形（ISO 3166-2）判定：距所有多边形超过约 2 km 的坐标视为境外并拒绝；目录层级与多边形一致的国家，来源区域与该多边形的名称、英文名、代码或目录名都不一致时改为多边形官方名称与代码。各国适用范围见本国文档。admin1 为省/省份/郡的混合层级国家（ES、FR、IT、PH、GB）：admin1 所属一级行政区与多边形不一致时视为错误，改为目录邮编在该多边形区域内对应的省份，省份按西班牙、法国的官方邮编前两位，其次目录邮编，意大利再按只属于单一省份的 CAP 前两位确定；都给不出时改为该一级行政区本身（意大利则下线该地址）；一级行政区一致而邮编与最近目录城市都指向同区内另一省份时改为该省份。名称不对应任何目录行政区的 admin1 不改，但若是行政代码所指地区名称的一部分（如“Алтай”），按代码改为该地区全称；最近目录城市只作邮编的佐证，不单独推断行政区。
- 一级行政区以来源名称文字为准：代码只在没有名称时按坐标推定（行政区多边形，不用目录中心点），名称与代码矛盾时以名称改正代码（意大利 admin1Code 为省缩写，不改）。代码比较忽略标点（`B.C.`、`A:K`）；“英文 / 法文”双语名任一部分唯一对应目录时采用该区并改为目录名；美、加、澳、巴的名称不对应任何一级行政区（如写成国家名 `Brasil`）时，只有城市位于代码所指一级行政区内才采用代码，否则仍视为目录外；其他国家未匹配的名称常是更完整的正式名（如 `Белгородская область`），保持原样。美、加、澳、巴本地与英文版保留邮政惯用代码（写法不规范的改为目录代码）；其他国家把写成代码的一级行政区改为目录本地名。美国属地 PR/VI/GU/AS/MP 使用固定中英文名。
- 本地语言组件中紧邻中日韩文字的“?”或 U+FFFD 视为编码损坏（`corrupted_text`），拒绝导入与发布；含表情符号或 U+FFFC 对象替换符的地址字段视为垃圾字符（`junk_characters`），同样拒绝，已发布的由行政名称复检下线。英文版的文字检查涵盖全部汉字扩展区（如 `𩵺`），无法转写的视为未译出。
- 行政目录上级关系按其城市所在的一级行政区多边形核验，错误的上级在目录覆盖中改正（ES Badajoz→Extremadura、FR Haute-Saône→Bourgogne-Franche-Comté、IT 托斯卡纳 8 省→Toscana、GB London→England）；菲律宾目录城市的省份归属由 `scripts/verify-catalog-city-regions.mjs` 按 COD-AB 省界逐一核定（`server/database/catalog-city-regions.json`），目录同步与启动覆盖都使用该表。
- 行政目录本地名以 Wikidata 本国语言标签核验（核验表 `server/database/catalog-native-corrections.json`，由 `scripts/verify-catalog-native-names.mjs` 生成并人工复核省级），英语国家使用英文名；曾用错误本地名补全的已存地址在其所属省内一次性改写。
- 门禁变化后，sync 启动时按国家和修订一次性复检已存地址：不合格的以 `publication-validation:<修订>:<时间>` 撤下，与已有地址重复的删除；所需外部数据不可用时修订保持未完成，下次启动补做。行政名称复检（`administrative-names-v9`）同时修正以 `publication-validation:` 撤下的地址（翻译回填会重新发布它们），这些地址保持撤下状态，与已发布地址重复的删除；结构与行政名称复检撤下的地址只由该复检的下一修订重新判定，翻译回填不会重新发布（其发布检查不含行政区多边形）；城市字段门禁也适用于中国香港、新加坡和中国台湾；混合层级国家按上述一级行政区多边形规则改正 admin1。复检同时撤下距所有一级行政区多边形超过约 2 km 的已发布地址（如记为意大利的圣马力诺地址）。全库质检另以 `outside_country`（同一多边形门禁）、`region_boundary`（混合层级国家 admin1 与多边形或邮编+城市矛盾）和 `postal_area`（开普敦地块邮编不在 7000–8099）为阻断规则。

## 翻译与发布

- 导入默认延迟翻译；回填按缓存优先，再按管理员为每个凭据设定的优先级调用（同级轮询，跳过不可用、冷却、额度耗尽或失败的路由），DeepL 只经 Credential Broker 使用 Free Key 并按码点预留额度。限速、鉴权、额度等待不等于来源耗尽。
- 只翻译语义字段；门牌、单元、邮编、行政代码与数字标识必须保持不变，供应商改动数字时只翻译文本片段并还原标识。中文组件出现问句、俄文通名缺失或长原名只剩单字时视为不可用。
- 目录能唯一确定的一级行政区与城市，中文使用目录名称并覆盖机器翻译（日本只补全不含汉字的中文名）；英文一级行政区使用目录英文名，英文城市名只在缺失或不是拉丁文字时补全；多个行政区共用的目录名称不使用；行政代码从不送机器翻译。全库质检另报告与目录邮编冲突的地址，因目录邮编表本身有错（如荷兰 4542 被归到弗里斯兰），只作复核，不阻断也不据此自动修改。中文版的地名（一级行政区、城市、区县）与原文相同且含字母时视为未译出，英语国家也不例外，留在翻译队列但保持发布。
- 普通地址的中文道路名未译出时可先以原名发布并留在翻译队列；住宅地址须完整中文版本。
- 中文完整地址由中文组件直接相连，仅在两侧都是汉字、假名以外的字母或数字时加空格，且必须与中文组件一致。
- 每批最多发布一个国家，批次 180 秒硬超时；发布事务只锁待发布地址行，对变更地址执行完整来源、地址和语言门禁。失败按指数退避最多 3 次，之后须输入或配置变化才重评；仅缓存的复检独立运行，不消耗翻译请求。
- 被发布校验撤下的地址只由翻译恢复复检合格后重新发布，重新导入不恢复它们。

## 生成与筛选

- 生成索引只是候选加速；返回前每条地址按当前质量、有效期、国家、住宅证据和筛选条件复检。
- 未筛选按连续序号等概率选择，筛选使用有界索引窗口；不加载全池、不全表随机排序。未传 seed 时每次请求生成新 seed，相同 seed 在同一快照可复现。
- 筛选选项只展示有可用地址的节点，管理覆盖树保留官方目录的零地址节点；邮编以生成索引中的完整码为准。
- 覆盖以官方行政目录为分母，按目录 ID 区分同名节点，歧义保留未映射；每次国家快照发布后重建总量与住宅覆盖。
