# JP 日本地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | 日本数字厅 Address Base Registry，经 Geolonia 月度构建的住居表示点与按市区町村的地番点；日本邮便邮编；PLATEAU/MLIT 建筑用途与轮廓；Geofabrik OSM 补充住宅轮廓。 |
| 格式 / 邮编 | 住居表示：`〒<postcode> <都道府県><市区町村><町名><丁目><街区符号>番<住居番号>号`；地番（住居表示未実施区域）：`〒<postcode> <都道府県><市区町村><町名>[<丁目>]<地番>番地[<支号>]`，含 `prc_num3` 的稀有地番直接淘汰。邮编只接受日本邮便 `utf_ken_all.csv` 对都道府县、市区町村、町域及丁目范围的唯一精确匹配；规范化为 `NNN-NNNN`，不按邻近点补齐。建筑名、室号缺失时保持为空。 |
| 行政区 | ABR `ja.json` 提供都道府县与市区町村；住居表示块提供町名、丁目、街区符号和住居番号。住居表示仅保留带丁目且能拆分出独立町域的记录，避免町域与街道字段重复；无丁目的地番町域只输出两级行政层级（district 置空），同样避免重复。政令指定都市按区级团体码（补前导零后取 5 位）映射到其 PLATEAU 城市包，修复了此前 exact-match 漏配导致的候选截断。 |
| 住宅证据 | ABR 只证明地址存在。住居表示点必须精确落入 PLATEAU `usage=residential` 建筑面，或当期 OSM 明确住宅建筑面；地番点必须恰好落入 1 个 PLATEAU 住宅建筑面且不落入任何非住宅建筑面，同一建筑含多个地番点时全部淘汰。不使用附近建筑。PLATEAU 转换包逐文件校验 SHA-256，OSM 非住宅 POI 与全局黑名单继续排除。 |
| 真实字段 / 生成字段 | ABR 的都道府县、市区町村、町名、丁目、街区/住居号或地番，日本邮便邮编及来源坐标均为真实字段；生成字段：无，建筑名和室号缺失时保持为空 |
| 坐标 / 去重 | 来源坐标统一为 WGS84；地址点必须精确落入住宅建筑面。按 ABR 稳定 ID、PLATEAU building uid 和规范化地址去重，住居表示优先于地番 |
| 发布门禁 | 质量高于数量。仅发布 E3：地址存在与独立住宅用途证据同时成立；本国格式规定的必填组件缺一即淘汰，字段冲突拒绝合并；只允许可逆、可验证的格式规范化。 |
| 同步方式 | 自动初始化依次执行 ABR 城市批次、PLATEAU 包、全国 OSM 可恢复扫描和最终发布；城市、建筑扫描、地番写入和 OSM 游标分别保存 checkpoint，进程超时或重启后自动续跑。完整扫描或来源耗尽后停止，显式来源探测发现版本变化时才重建 |
| 验证 / 排除 | ABR 地址点必须唯一落入 PLATEAU/OSM 明确住宅建筑面，并唯一匹配日本邮便 7 位邮编；缺字段、校验失败、非住宅名称及多地番歧义记录全部淘汰。 |
| 策略版本 / 状态 / 更新 | 3.3（`abr-rsdt-plateau-osm-chiban-v14`）/ 分块提交候选、城市级幂等恢复 + STRtree 空间匹配 + PLATEAU 29 城 + 全国 OSM 住宅补充 + 地番扩展 / 2026-08-24 |

- 默认 active 地址及本来源上限 20,000；都道府县、市区町村、町域单节点上限 7,000/1,000/200，后台可覆盖；最低行政节点先均衡保留 5 条，只裁剪地址记录，行政区划与邮编目录保持完整。
- 同一源版本产生 0 条合格记录时标记 `SOURCE_QUALITY_FAILED`，只重查源版本元数据；上游版本或适配/清洗版本变化后自动重试。
- 首次严格快照只要存在合格记录即可发布；后续快照仍执行数量与行政覆盖防回退门禁，避免因总量目标阻塞真实的小规模数据。
- 地番扩展在住居表示匹配后按 PLATEAU 城市包流式执行。仅保留含登记所坐标、纯数字地番且无 `prc_num3` 的记录；地番点必须恰好落入一个住宅建筑面且不落入非住宅建筑面。以 PLATEAU building uid 去重，住居表示优先，避免同一住宅以住居表示与地番重复计数。
- 当前提取指纹的候选库和 checkpoint 会跨任务、进程与容器重启保留；来源版本或提取能力指纹变化时适配器自动替换旧状态。已完成的 PLATEAU/OSM 原始资产立即回收，PID 临时文件、下载残片和解压目录由周期清理器自动处理。


默认同步生命周期为自动初始化一次；未完成的额度或 checkpoint 任务自动续跑，完整扫描或来源耗尽后停止，不按日/月重复执行。只有来源、上游版本、严格提取能力变化或管理员明确刷新才重新运行；周期元数据探测仅在显式启用时执行。

统一证据等级、许可、配额与 VPS 边界见 [数据源与自动同步方案](../data-sources.md)。策略变化时同步更新本文件、实现与测试。
## 覆盖与保留

- 官方行政区目录定义覆盖分母；只有关联到官方节点的严格住宅地址计入分子。
- 每个有合格数据的最低行政区先满足每节点、省市和单节点目标，再轮询分配额外记录；国家总量是完成下限，节点规则可推动总量继续增长，来源或分片容量仍是技术硬限制。
- 每次国家快照发布后自动重建住宅覆盖；生成器只展示至少有 1 条可发布住宅地址的官方区域。


## 运行时随机生成

- 公开普通生成直接在 PostgreSQL 完整合格范围选择：支持连续生成序号的未筛选国家池按序号等概率选择，筛选范围使用有界循环索引窗口；不使用固定子集或固定顺序。
- 每次按 seed 在有界候选窗口内执行独立偏移，再按主键读取完整地址与证据；API 不把完整地址池加载到进程内存，也不执行全表随机排序。
- 未传入 seed 时由服务器为每个请求生成新 UUID；相同显式 seed 在同一数据库快照中可复现。数据库提交后，新 worker 快照全部就绪才原子替换旧快照。
