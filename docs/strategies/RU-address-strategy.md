# RU 俄罗斯地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | Geofabrik OpenStreetMap `russia` |
| 既有门牌级格式 / 邮编 | `<postcode>, <region>, <locality>, <street>, <house>`； корпус/квартира 缺失不补；源记录；格式门禁 6 位数字。只清洗格式，不创造或按邻近地址补齐 |
| 行政区 | Rosstat/行政区目录作为候选核验；当前源字段与 catalog 反查，含坐标锚定与 Cyrillic 清洗。行政层级必须与坐标反查一致；冲突时保留源值在隔离区并拒绝发布；“Белгородская область”等全称与目录简称视为同一地区，无法区分的“Алтай”按坐标多边形改正；目录中文名改为“XX州/边疆区/共和国”（administrative-names-v19） |
| 住宅子集证据 | OSM 明确住宅建筑标签；行政区文本与坐标冲突时丢弃。住宅证据必须来自明确建筑/用途字段，不能由地址存在推断 |
| 真实字段 / 生成字段 | 门牌、道路、locality、联邦主体、邮编、可选 корпус/квартира 和坐标来自 OSM；生成字段：无 |
| 坐标 / 去重 | OSM WGS84 坐标通过俄罗斯边界与脚本门禁；按 OSM ID 和规范化西里尔文地址 canonical hash 去重 |
| 街道级格式 | `<federal subject>, <locality>, <street>, RU`；`matchLevel=street`，门牌、楼栋、室号为空；可唯一确定的来源邮编保留，否则留空。 |
| 街道去重 / 验证 | 国家 + 规范行政层级 + 街道名，同一路段不同坐标、邮编或来源 ID 不增加条数；行政字段不使用最近目录点推断。 |
| 同步方式 | 自动初始化一次；完整扫描或来源耗尽后停止。显式来源探测发现 Geofabrik 版本变化时才构建新快照 |
| 既有门牌来源验证 / 排除 | 俄语行政层级不能从街道名猜测；跨境、缺字段和脚本异常记录直接拒绝 |
| 策略版本 / 状态 / 更新 | 1.13 / 严格住宅点面关联 + 多规则完成下限 + 街道契约 street-v1 + address-structure-v1 + administrative-names-v19 + 热门优先 / 2026-10-20 |
共用规则（翻译、发布、生成、同步框架和结构门禁）见 [README.md](README.md)；本文件只记录本国差异。

- 上游目录把阿尔泰边疆区（ALT）写成与阿尔泰共和国（AL）完全相同的名称，目录覆盖改为 Altai Krai / Алтайский край / 阿尔泰边疆区 与 Altai Republic / Республика Алтай / 阿尔泰共和国；已存地址的简称“Алтай”按其行政代码改为对应全称。莫斯科市与莫斯科州英文同名，层级接口以俄文名作为筛选值。

- 默认国家完成数量下限 20,000；联邦主体、市/区、地区单来源均衡采样上限 2,000/300/70，后台可覆盖；国家总量不是发布上限，行政区划与邮编目录保持完整。

- OSM 独立地址点仅在精确落入明确住宅建筑面时获得住宅用途证据；不使用附近建筑、同街道或邻近坐标推断。

## 既有来源街道提取（2026-09-08）

- Geofabrik `g70-streets` 提取来源命名道路及已有门牌，保留真实行政字段；道路点位于原始线几何，按国家/行政层/道路去重，不从最近目录点补行政区。街道邮编、楼栋、单元和住宅证据为空；非住宅门牌保留但不获得住宅用途。

- 单次上限（capacity-20261003）：geofabrik（1 个分片）：单次上限 200,000。

- 来源缺少邮编时按顺序推断，且只在结果唯一时填写，冲突一律留空：
  1. GeoNames 邮编目录中同一一级行政区下该城市或区县只对应一个邮编，且目录坐标在约 30 km 内（CC BY 4.0）；
  2. 同一城市约 1 km 范围内至少 3 条来源自带邮编的地址邮编一致（推断出的邮编不参与投票）。

## 目录本地名核验（2026-10-11）

- 目录本地名修正：省级 28 条、城市 118 条（已存地址由 catalog-native-addresses-v2 一次性改写）。

- 来源分片（2026-10-11）：Geofabrik 俄罗斯整包（3.9 GB）提取超过 75 分钟进程上限，改为 Geofabrik 的 9 个子区域分片（各联邦区与加里宁格勒）；克里米亚在 Overture 一级行政区多边形中不属于俄罗斯，坐标门禁会将其判为境外，因此不再提取该分片；每片单次上限 200,000。旧整包数据集保留为已有证据，新分片独立记录版本、耗尽和失败状态。

- 一级行政区多边形：纠正与坐标冲突或无法识别的来源区域，并排除境外坐标。
