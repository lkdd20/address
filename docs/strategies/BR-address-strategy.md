|---|---|
| 主源 | Geofabrik `brazil` |
| 既有门牌级格式 / 邮编 | `<street>, <number>, <neighborhood>, <city> - <UF>, <CEP>, BR`；complemento 缺失不补；源记录；格式门禁 `\d{5}-?\d{3}`。只清洗格式，不创造或按邻近地址补齐 |
| 行政区 | 源字段与 catalog；IBGE 行政区作为候选核验。行政层级必须与坐标反查一致；冲突时保留源值在隔离区并拒绝发布 |

| 同步方式 | 自动初始化一次；checkpoint 自动续跑，完整扫描或来源耗尽后停止。显式来源探测发现 Geofabrik 版本变化时才构建新快照 |
| 既有门牌来源验证 / 排除 | UF 必须与行政目录一致；葡萄牙语重音保留；缺少真实道路、必填行政字段或坐标的记录拒绝发布；未知 CEP 留空，住宅建筑证据仅用于住宅子集 |
| 策略版本 / 状态 / 更新 | 1.13 / 严格住宅点面关联 + 多规则完成下限 + 街道契约 street-v1 + address-structure-v1 + administrative-names-v19 + 热门优先 / 2026-10-20 |
共用规则（翻译、发布、生成、同步框架和结构门禁）见 [README.md](README.md)；本文件只记录本国差异。

- 默认国家完成数量下限 20,000；州、市、区单来源均衡采样上限 1,500/250/60，后台可覆盖；国家总量不是发布上限，行政区划与邮编目录保持完整。

- OSM 独立地址点仅在精确落入明确住宅建筑面时获得住宅用途证据；不使用附近建筑、同街道或邻近坐标推断。

## 既有来源街道提取（2026-09-08）

- Geofabrik `g70-streets` 提取来源命名道路及已有门牌，保留真实行政字段；道路点位于原始线几何，按国家/行政层/道路去重，不从最近目录点补行政区。街道邮编、楼栋、单元和住宅证据为空；非住宅门牌保留但不获得住宅用途。

## 城市级契约与行政边界补全（2026-10-01）

- 必填行政层级降为“一级行政区（如适用）+ 城市”，district 改为可选：来源有值时保留，缺失时用官方/开放行政边界按坐标补全，补不到则留空，不再整条拒绝。街道和门牌仍必须来自来源，坐标、国家边界、语言和邮编门禁不变。
- 边界数据：IBGE Censo 2022 街区边界 `BR_bairros_CD2022`（NM_BAIRRO）→ district；Overture divisions `neighborhood`/`macrohood` 兜底。
- 补全规则：只填补来源为空的 district，或与城市同名的 district；来源已有值不覆盖；坐标不落在任何边界内则不补；城市只在来源与目录补全后仍为空时用边界补。边界名称直接取自数据集，不翻译反推。
- Geofabrik、Overture、OpenAddresses 三类批量来源的能力指纹附加本国边界版本，仅这些来源因能力变化重新执行一次；其他来源的耗尽状态不受影响。

- 单次上限（capacity-20261003）：overture（1 个分片）：单次上限 200,000；geofabrik（1 个分片）：单次上限 200,000。

- 本国邮编精细到街道或楼栋（或不使用邮编），不按区域或邻近地址推断；来源缺失时保持留空。

## 目录本地名核验（2026-10-11）

- 目录本地名修正：省级 0 条、城市 507 条（已存地址由 catalog-native-addresses-v2 一次性改写）。

- 一级行政区多边形：纠正与坐标冲突或无法识别的来源区域，并排除境外坐标。

## 热门城市与热门地区优先（2026-10-19）

- Overture 导出改为热门优先配额（详见共用规则）：先统计各“一级行政区+城市”的地址数，每个城市保底 10 条，热门城市的都市圈（按名称或中心坐标半径归圈）补到每圈共 30,000 条，其余预算按目录人口平方根加权；按记录 ID 哈希切片抽样，预算增大只追加不替换。适配器修订为 `addresses-streets-residential-subset-v7-popular-cities`，所有 Overture 分片按新能力重新评估。
