# SG 新加坡地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | HDB Property Information + HDB Existing Building；OneMap 精确补齐；Geofabrik OSM 作为补充 |
| 格式 / 邮编 | `<BLK_NO> <ROAD_NAME>, Singapore <POSTAL>`；HDB 真实楼栋号、道路、6 位邮编和 WGS84 建筑坐标，字段缺失即淘汰，不生成门牌或邮编 |
| 行政区 | `Singapore` + HDB `bldg_contract_town` 官方城镇；未知代码拒绝发布。OneMap 只补齐同楼栋号、同规范化道路名的唯一邮编与坐标 |
| 住宅证据 | Property Information 必须同时满足 `residential=Y`、`total_dwelling_units>0`；Existing Building 或 OneMap 提供地址存在、邮编和坐标证据，OneMap 本身不证明住宅用途 |
| 真实字段 / 生成字段 | HDB 楼栋、道路、规划城镇、住宅单元数及 OneMap 唯一匹配的邮编和坐标均为来源字段；生成字段：无，不生成门牌或邮编 |
| 坐标 / 去重 | OneMap/HDB 坐标统一为 WGS84；按 HDB 楼栋 ID、规范化楼栋号+道路及唯一邮编去重 |
| 发布门禁 | 质量高于数量。仅发布 E3：地址存在与独立住宅用途证据同时成立；本国格式规定的必填组件缺一即淘汰，字段冲突拒绝合并；只允许可逆、可验证的格式规范化。 |
| 同步频率 | 首次初始化自动运行；完成或来源耗尽后停止，不按日/月重复同步。只有新增来源、上游版本或适配器提取能力变化，以及管理员明确刷新时才重新执行。OneMap 只通过共享 Credential Broker 调用，按 `1 QPS` 节流；每轮最多处理 500 个未缓存查询并保存 checkpoint，短时限速在同一任务内有限重试，真实额度、凭据或网络暂不可用时恢复后自动续跑。 |
| 验证 / 排除 | HDB 属性与建筑必须一对一匹配；OneMap 结果必须满足楼栋号、规范化道路名、唯一 6 位邮编和坐标门禁。无匹配、多邮编歧义或字段缺失全部淘汰。 |
| 策略版本 / 状态 / 更新 | 2.0 / HDB 双表 + OneMap 分批限速续跑 + 一次性初始化 + 多规则完成下限 / 2026-08-24 |

- 默认国家完成数量下限 12,000；规划区层级单来源均衡采样上限 12,000/1,000/100，后台可覆盖。完成数量不是发布上限，严格记录可继续发布以满足覆盖和节点规则。

- HDB 两表优先一对一连接；未命中时只接受 OneMap 中楼栋号和规范化道路名一致、且只有一个有效邮编的结果。重复楼栋、邮编歧义、无住宅单元、无邮编或无坐标的记录全部淘汰。
- `zh-CN` 道路、城镇或国家字段至少一个必须包含汉字；历史纯英文占位变体在自动翻译回填完成前不进入生成池，回填完成后无需人工干预即可恢复发布。


默认同步生命周期为自动初始化一次；未完成的额度或 checkpoint 任务自动续跑，完整扫描或来源耗尽后停止，不按日/月重复执行。只有来源、上游版本、严格提取能力变化或管理员明确刷新才重新运行；周期元数据探测仅在显式启用时执行。

统一证据等级、许可、配额与 VPS 边界见 [数据源与自动同步方案](../data-sources.md)。策略变化时同步更新本文件、实现与测试。
## 覆盖与保留

- 官方行政区目录定义覆盖分母；只有关联到官方节点的严格住宅地址计入分子。
- 每个有合格数据的最低行政区先满足每节点、省市和单节点目标，再轮询分配额外记录；国家总量是完成下限，节点规则可推动总量继续增长，来源或分片容量仍是技术硬限制。
- 每次国家快照发布后自动重建住宅覆盖；生成器只展示至少有 1 条可发布住宅地址的官方区域。


## 运行时随机生成

- 公开普通生成直接在 PostgreSQL 完整合格范围选择：支持连续生成序号的未筛选国家池按序号等概率选择，筛选范围使用有界循环索引窗口；不使用固定子集或固定顺序。
- 每次按 seed 在有界候选窗口内执行独立偏移，再按主键读取完整地址与证据；API 不把完整地址池加载到进程内存，也不执行全表随机排序。
- 未传入 seed 时由服务器为每个请求生成新 UUID；相同显式 seed 在同一数据库快照中可复现。数据库提交后，新 worker 快照全部就绪才原子替换旧快照。
