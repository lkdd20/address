# MX 墨西哥地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | INEGI 全国地址框架原始 SHP/DBF；Digital Guard 保全包仅作可复现下载入口；OpenAddresses 同源标准化包只补充州/城市名称，不提供住宅证据 |
| 既有门牌级格式 / 邮编 | `<street> <house>, <colonia>, <municipio>, <estado>, <CP>, MX`；缺失字段留空；源记录；格式门禁 5 位数字。只清洗格式，不创造或按邻近地址补齐 |
| 行政区 | INEGI Marco Geoestadístico/municipios 作为候选交叉核验；Overture `address_levels` 完整保留并确定性映射州、市镇和最细来源层级。行政层级必须与坐标反查一致；冲突时保留源值在隔离区并拒绝发布 |
| 住宅子集证据 | 原始记录必须满足 `TIPODOM=VIVIENDA`；商业/政府/学校等黑名单剔除。住宅用途直接来自 INEGI 字段，不由地址存在或邻近建筑推断 |
| 真实字段 / 生成字段 | INEGI 门牌、道路、colonia、municipio、estado、邮编、坐标和 `TIPODOM` 均为来源字段；同源标准化包只映射名称。生成字段：无 |
| 坐标 / 去重 | INEGI 坐标统一为 WGS84 并通过墨西哥边界门禁；按来源 ID 和规范化地址 canonical hash 去重 |
| 街道级格式 | `<street>, <colonia>, <municipality>, <state code>, MX`；`matchLevel=street`，门牌、楼栋、室号为空；可唯一确定的来源邮编保留，否则留空。 |
| 街道去重 / 验证 | 国家 + 规范行政层级 + 街道名，同一路段不同坐标、邮编或来源 ID 不增加条数；行政字段不使用最近目录点推断。 |
| 同步方式 | 自动初始化一次；完整扫描或来源耗尽后停止。显式来源探测发现 INEGI 包版本或提取能力变化时才构建新快照 |
| 既有官方住宅适配器 / 排除 | 仅保留 `VIVIENDA` 且真实门牌、街道、住区、5 位非零邮编和合法坐标完整的记录；`SN`、`NINGUNO`、`00000` 全部淘汰。 |
| 策略版本 / 状态 / 更新 | 1.12 / INEGI 直接住宅用途 + 多规则完成下限 + 街道契约 street-v1 + address-structure-v1 / 2026-10-11 |
共用规则（翻译、发布、生成、同步框架和结构门禁）见 [README.md](README.md)；本文件只记录本国差异。

- 默认国家完成数量下限 20,000；州、市镇、地区单来源均衡采样上限 2,000/300/70，后台可覆盖；国家总量不是发布上限，行政区划与邮编目录保持完整。
- 原始 ITRF92 Lambert 坐标按源投影参数转换为 WGS84，并与同源标准化坐标精确匹配；原始门牌、街道、住区和邮编优先，不接受标准化包覆盖原始邮编。
- 首次严格快照只要存在合格记录即可发布；后续快照仍执行数量与行政覆盖防回退门禁。

## 既有来源街道提取（2026-09-08）

- Geofabrik `g70-streets` 提取来源命名道路及已有门牌，保留真实行政字段；道路点位于原始线几何，按国家/行政层/道路去重，不从最近目录点补行政区。街道邮编、楼栋、单元和住宅证据为空；非住宅门牌保留但不获得住宅用途。
- Overture `addresses-streets-residential-subset-v6` 保留来源街道和未匹配住宅建筑的真实门牌；仅实际相交且有明确住宅类别的门牌获得住宅证据，街道不得因落入建筑面而获得住宅用途。候选先去重再均衡采样；建筑分类失败保留地址事实，不伪造住宅证据。

- 单次上限（capacity-20261003）：overture（1 个分片）：单次上限 200,000；inegi-residential（1 个分片）：单次上限 100,000；geofabrik（1 个分片）：单次上限 200,000。

- 来源缺少邮编时按顺序推断，且只在结果唯一时填写，冲突一律留空：
  1. GeoNames 邮编目录中同一一级行政区下该城市或区县只对应一个邮编，且目录坐标在约 30 km 内（CC BY 4.0）；
  2. 同一城市约 1 km 范围内至少 3 条来源自带邮编的地址邮编一致（推断出的邮编不参与投票）。
