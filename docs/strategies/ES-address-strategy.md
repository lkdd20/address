# ES 西班牙地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | Dirección General del Catastro INSPIRE（Madrid 28900、Salamanca 37900、Albarracín 44009）+ Overture Maps addresses + Geofabrik Spain OSM 日更快照 |
| 格式 / 邮编 | `<street> <house>, <postcode> <municipality>, <province>, ES`；楼梯/门号仅保留真实字段；源记录；格式门禁 5 位数字。只清洗格式，不创造或按邻近地址补齐 |
| 行政区 | INE/IGN 行政边界作为候选核验；当前源字段与 catalog 反查。行政层级必须与坐标反查一致；冲突时保留源值在隔离区并拒绝发布 |
| 住宅证据 | Catastro BU `currentUse=1_residential` 且 `numberOfDwellings>0`，通过 14 位 referencia catastral 与 AD 地址稳定关联；其他源仍须具备明确住宅建筑/用途证据 |
| 真实字段 / 生成字段 | Catastro AD 的门牌、道路、市镇、邮编、语言和建筑关联键及其他来源地址字段均为真实字段；生成字段：无 |
| 坐标 / 去重 | Catastro EPSG:25830 坐标确定性转换为 WGS84；其他来源统一为 WGS84。按 referencia catastral/来源 ID 和规范化地址去重 |
| 发布门禁 | 质量高于数量。仅发布 E3：地址存在与独立住宅用途证据同时成立；本国格式规定的必填组件缺一即淘汰，字段冲突拒绝合并；只允许可逆、可验证的格式规范化。 |
| 同步方式 | 自动初始化一次；显式来源探测发现 Catastro municipality ATOM 包或其他上游版本变化时才重建。新快照原子切换，失败保留上一 active 快照 |
| 验证 / 排除 | Catastro AD 门牌、道路、5 位邮编、`esp` 语言、municipality admin unit 和 EPSG:25830 坐标均必填，坐标确定性转换为 WGS84；邮编前两位只作一致性检查，不能反推地址。 |
| 策略版本 / 状态 / 更新 | 1.5 / Catastro 住宅建筑与地址稳定关联 + 解除旧区域容量截断 + 严格多规则完成下限 / 2026-08-24 |

- 默认国家完成数量目标 80,000；它只是完成下限，不是发布上限。自治区、市镇、区采样上限为 80,000/70,000/300，允许完整接纳 Madrid 严格住宅候选。Catastro 三个已审计分片最多选择 80,500 条严格候选；行政区划与邮编目录保持完整。适配器能力版本 `inspire-residential-join-v2` 使此前被旧自治区采样上限截断的合格集合重新接受自动评估。


默认同步生命周期为自动初始化一次；未完成的额度或 checkpoint 任务自动续跑，完整扫描或来源耗尽后停止，不按日/月重复执行。只有来源、上游版本、严格提取能力变化或管理员明确刷新才重新运行；周期元数据探测仅在显式启用时执行。

统一证据等级、许可、配额与 VPS 边界见 [数据源与自动同步方案](../data-sources.md)。策略变化时同步更新本文件、实现与测试。
## 覆盖与保留

- 官方行政区目录定义覆盖分母；只有关联到官方节点的严格住宅地址计入分子。
- 每个有合格数据的最低行政区先满足每节点、省市和单节点目标，再轮询分配额外记录；国家总量是完成下限，节点规则可推动总量继续增长，来源或分片容量仍是技术硬限制。
- 每次国家快照发布后自动重建住宅覆盖；生成器只展示至少有 1 条可发布住宅地址的官方区域。


## 运行时随机生成

- 公开普通生成直接在 PostgreSQL 完整合格范围选择：支持连续生成序号的未筛选国家池按序号等概率选择，筛选范围使用有界循环索引窗口；不使用固定子集或固定顺序。
- 每次按 seed 在有界候选窗口内执行独立偏移，再按主键读取完整地址与证据；API 不把完整地址池加载到进程内存，也不执行全表随机排序。
- 未传入 seed 时由服务器为每个请求生成新 UUID；相同显式 seed 在同一数据库快照中可复现。数据库提交后，新 worker 快照全部就绪才原子替换旧快照。
