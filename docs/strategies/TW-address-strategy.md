# TW 中国台湾地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | 内政部实价登录多季度包：仅取 `主要用途=住家用/国民住宅` 且交易标的含房地的真实成交门牌；OpenAddresses 台湾地方政府门牌点仅补精确坐标 |
| 既有门牌级格式 / 邮编 | `<3+3郵遞區號> <縣市><鄉鎮市區><村里（有值才显示）><路街/段巷弄><號>`；只接受中华邮政官方六位邮递区号，三位旧值隔离，不补造后三位。 |
| 行政区 | 一级统一语义为 `縣市`，二级统一语义为 `鄉鎮市區`（直辖市/市的區、县的鄉鎮市），村/里仅有官方值时显示；`admin1/locality`、经纬度和台湾范围任一冲突即淘汰 |
| 住宅子集证据 | 实价登录的明确住宅主要用途和住宅建筑型态共同证明住宅属性；OA 点必须与完整门牌唯一精确关联，不以邻近点或邮编推断 |
| 真实字段 / 生成字段 | 成交门牌、縣市、鄉鎮市區、可选村里、住宅用途/型态、精确 3+3 邮编和唯一坐标均来自官方或精确关联来源；生成字段：无 |
| 坐标 / 去重 | 来源坐标统一为 WGS84 并通过台湾边界门禁；季度包按规范化完整门牌跨季度去重，保留最新来源记录 |
| 街道级格式 | `<縣市><鄉鎮市區><路街/段巷弄>`；`matchLevel=street`，门牌、楼栋、室号为空；可唯一确定的来源邮编保留，否则留空。 |
| 街道去重 / 验证 | 国家 + 规范行政层级 + 街道名，同一路段不同坐标、邮编或来源 ID 不增加条数；行政字段不使用最近目录点推断。 |
| 同步方式 | 使用内政部季度包、OA 亚洲归档和可断点续跑的邮编缓存；季度包按新到旧合并，以规范化完整门牌跨季度去重；429、5xx 与网络失败有限重试，合格快照原子切换。 |
| 既有官方住宅适配器 / 排除 | 新旧季度同门牌只保留最新记录；每条记录必须通过中华邮政规范化地址与 6 位邮编完全一致门禁。 |
| 策略版本 / 状态 / 更新 | 2.7 / 多季度归档合并 + 多规则完成下限 + 街道契约 street-v1 + address-structure-v1 + administrative-names-v9（仅城市字段门禁） / 2026-10-13 |
共用规则（翻译、发布、生成、同步框架和结构门禁）见 [README.md](README.md)；本文件只记录本国差异。

- 英文版门牌按中华邮政英文格式输出：34號＋之1 为 `No. 34-1`，四樓之2 为 `4F.-2`，地下一樓为 `B1F.`，纯数字室号为 `Rm. N`；无法按此规则转写且英文仍含汉字的地址不发布。
- 默认 active 地址及本来源上限 10,000；县市、区乡镇、村里单来源均衡采样上限 2,000/300/70，后台可覆盖；国家总量不是发布上限，行政区划与邮编目录保持完整。规范化缓存身份包含有效记录上限和行政节点上限，策略变化后不复用不匹配的旧缓存。
- 官方组合源首次发布至少保留 4,000 条严格记录并覆盖至少 5 个县市；门槛只控制快照数量，不放宽住宅用途、门牌、坐标、邮编或行政区验证。
- 既有实价登录住宅适配器仍要求完整门牌、住宅用途、住宅建筑型态、唯一坐标与精确 3+3 邮编；该来源门禁不适用于 Geofabrik/Overture 的普通真实街道与门牌。

## 既有来源街道提取（2026-09-08）

- Geofabrik `g70-streets` 提取来源命名道路及已有门牌，保留真实行政字段；道路点位于原始线几何，按国家/行政层/道路去重，不从最近目录点补行政区。街道邮编、楼栋、单元和住宅证据为空；非住宅门牌保留但不获得住宅用途。
- Overture `addresses-streets-residential-subset-v6` 保留来源街道和未匹配住宅建筑的真实门牌；仅实际相交且有明确住宅类别的门牌获得住宅证据，街道不得因落入建筑面而获得住宅用途。候选先去重再均衡采样；建筑分类失败保留地址事实，不伪造住宅证据。

- 单次上限（capacity-20261003）：overture（1 个分片）：单次上限 200,000；taiwan-residential（1 个分片）：单次上限 100,000；geofabrik（1 个分片）：单次上限 200,000。

- 来源缺少邮编时按顺序推断，且只在结果唯一时填写，冲突一律留空：
  1. GeoNames 邮编目录中同一一级行政区下该城市或区县只对应一个邮编，且目录坐标在约 30 km 内（CC BY 4.0）；
  2. 台湾 3 码邮递区号按乡镇市区划定：同一县市（「台」「臺」视为相同）同一乡镇市区内至少 3 条来源自带邮编、且前 3 码全部一致时，填写该 3 码（方法 `township-consensus`，修订 `postcode-inference-v1+township`）；同一乡镇出现不同前 3 码则不填；
  3. 同一城市约 1 km 范围内至少 3 条来源自带邮编的地址邮编一致（推断出的邮编不参与投票）。
- GeoNames 台湾目录仅有英文（威妥玛式）乡镇名，与地址的中文名及汉语拼音英文版本无法可靠对应，实测目录匹配为 0，台湾主要依靠第 2、3 步。

## 县市与乡镇官方写法（2026-10-08）

- 导入时县市（一级行政区）与乡镇市区名称开头的「台」统一为官方写法「臺」（如 `臺北市`、`臺東縣`、`臺東市`），村里名称保持来源原样。
- 同步服务启动时一次性修正已存地址（修订 `taiwan-official-name-v1`）：更新本地语言组件、行政字段、规范去重键和生成索引；修正后与已有官方写法地址重复的行删除，保留原官方写法行。

## 目录本地名核验（2026-10-11）

- 目录本地名修正：省级 20 条、城市 0 条（已存地址由 catalog-native-addresses-v2 一次性改写）。

- 一级行政区多边形：目录层级与多边形不一致，仅排除境外坐标，不改写来源区域。
