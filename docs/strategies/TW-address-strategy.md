# TW 中国台湾地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | 内政部实价登录多季度包：仅取 `主要用途=住家用/国民住宅` 且交易标的含房地的真实成交门牌；OpenAddresses 台湾地方政府门牌点仅补精确坐标 |
| 格式 / 邮编 | `<3+3郵遞區號> <縣市><鄉鎮市區><村里（有值才显示）><路街/段巷弄><號>`；只接受中华邮政官方六位邮递区号，三位旧值隔离，不补造后三位。 |
| 行政区 | 一级统一语义为 `縣市`，二级统一语义为 `鄉鎮市區`（直辖市/市的區、县的鄉鎮市），村/里仅有官方值时显示；`admin1/locality`、经纬度和台湾范围任一冲突即淘汰 |
| 住宅证据 | 实价登录的明确住宅主要用途和住宅建筑型态共同证明住宅属性；OA 点必须与完整门牌唯一精确关联，不以邻近点或邮编推断 |
| 真实字段 / 生成字段 | 成交门牌、縣市、鄉鎮市區、可选村里、住宅用途/型态、精确 3+3 邮编和唯一坐标均来自官方或精确关联来源；生成字段：无 |
| 坐标 / 去重 | 来源坐标统一为 WGS84 并通过台湾边界门禁；季度包按规范化完整门牌跨季度去重，保留最新来源记录 |
| 发布门禁 | 质量高于数量。仅发布 E3：地址存在与独立住宅用途证据同时成立；本国格式规定的必填组件缺一即淘汰，字段冲突拒绝合并；只允许可逆、可验证的格式规范化。 |
| 同步方式 | 使用内政部季度包、OA 亚洲归档和可断点续跑的邮编缓存；季度包按新到旧合并，以规范化完整门牌跨季度去重；429、5xx 与网络失败有限重试，合格快照原子切换。 |
| 验证 / 排除 | 新旧季度同门牌只保留最新记录；每条记录必须通过中华邮政规范化地址与 6 位邮编完全一致门禁。 |
| 策略版本 / 状态 / 更新 | 2.0 / 多季度归档合并 + 多规则完成下限 / 2026-08-24 |

- 默认 active 地址及本来源上限 10,000；县市、区乡镇、村里单节点上限 2,000/300/70，后台可覆盖；只裁剪地址记录，行政区划与邮编目录保持完整。规范化缓存身份包含有效记录上限和行政节点上限，策略变化后不复用不匹配的旧缓存。
- 官方组合源首次发布至少保留 4,000 条严格记录并覆盖至少 5 个县市；门槛只控制快照数量，不放宽住宅用途、门牌、坐标、邮编或行政区验证。
- 缺少完整门牌、住宅用途、住宅建筑型态、唯一坐标或精确 3+3 邮编中的任一项，记录不进入候选池。


默认同步生命周期为自动初始化一次；未完成的额度或 checkpoint 任务自动续跑，完整扫描或来源耗尽后停止，不按日/月重复执行。只有来源、上游版本、严格提取能力变化或管理员明确刷新才重新运行；周期元数据探测仅在显式启用时执行。

统一证据等级、许可、配额与 VPS 边界见 [数据源与自动同步方案](../data-sources.md)。策略变化时同步更新本文件、实现与测试。
## 覆盖与保留

- 官方行政区目录定义覆盖分母；只有关联到官方节点的严格住宅地址计入分子。
- 每个有合格数据的最低行政区先满足每节点、省市和单节点目标，再轮询分配额外记录；国家总量是完成下限，节点规则可推动总量继续增长，来源或分片容量仍是技术硬限制。
- 每次国家快照发布后自动重建住宅覆盖；生成器只展示至少有 1 条可发布住宅地址的官方区域。


## 运行时随机生成

- 公开普通生成直接在 PostgreSQL 完整合格范围选择：支持连续生成序号的未筛选国家池按序号等概率选择，筛选范围使用有界循环索引窗口；不使用固定子集或固定顺序。
- 每次按 seed 在有界候选窗口内执行独立偏移，再按主键读取完整地址与证据；API 不把完整地址池加载到进程内存，也不执行全表随机排序。
- 未传入 seed 时由服务器为每个请求生成新 UUID；相同显式 seed 在同一数据库快照中可复现。数据库提交后，新 worker 快照全部就绪才原子替换旧快照。
