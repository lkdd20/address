# 各国地址格式与邮编规则

更新：2026-08-24。格式化只重排、规范化来源字段，不生成缺失的地址事实。发布层使用与本表一致的国家契约；不符合契约的来源记录进入隔离区。

## 通用规则

- **质量高于数量**：下表必填组件缺少任意一项，整条记录拒绝发布，不进入随机地址池。
- 原文地址是主表示；英文和简体中文是同一组真实组件的转写/翻译。
- 简体中文变体的道路、城市、区县或一级行政区等语义字段必须至少有一个汉字；只有英文占位内容的记录在翻译回填完成前不发布。
- 随机索引与直接查询使用同一中文发布门禁。历史英文占位记录由后台按有界批次自动回填，地址同步运行期间仍会推进；回填成功后索引自动刷新。
- 邮编只接受来源值或精确权威关联值；除中国 POI 和香港外，邮编缺失或格式错误均淘汰整条记录。
- 行政区必须与来源坐标和本地 catalog 一致；冲突记录隔离。
- 行政字段按官方语义固定：筛选目录与邮寄地址行分开；城市、地点、行政区不得互相复制或降级替代。
- 只有美国、加拿大、澳大利亚、巴西、墨西哥、意大利在邮寄行强制使用一级行政标准代码；其他国家不生成伪造的行政缩写。道路类型缩写只在来源已有或该国邮政规范明确要求时保留。
- 原生语言执行脚本门禁：CN 简体中文、HK/TW 繁体中文、JP 日文、KR 韩文、TH 泰文、SA 阿拉伯文、RU 西里尔文；英文和简体变体独立保存，不与原生字段混写。
- 只允许大小写、空白、全半角和标准分隔符等可逆规范化；附近邮编、邻近地址、翻译反推和随机补值全部禁止。
- `unit` 与 `buildingName` 分开保存；来源数字单元按国家格式显示为 `Apt 3`、`Flat 3`、`Unit 3` 等，不再显示为建筑名 `3`。
- 建筑名和室内字段是可选事实，只有 `official` 或 `source_tagged` 来源才显示；人物、工作、财务、网络和沙盒银行卡属于合成测试资料。

## 格式表

| 国家/地区 | 原文展示顺序 | 必填组件 | 邮编门禁 |
|---|---|---|---|
| 中国 CN | `省/直辖市 + 市 + 区县 + 街道/道路 + 门牌 + 小区` | 省、市、区县、来源道路、来源门牌、小区名 | 精确来源存在时仅接受 6 位；POI 发布不强制邮编 |
| 中国香港 HK | `室/楼层 + 大厦 + 门牌道路 + 地点 + 18区 + 三大地域` | 门牌、道路、地点、官方18区、香港島/九龍/新界 | 无通用邮编；`999077` 仅兼容占位值，不进入 canonical postcode |
| 中国台湾 TW | `郵遞區號 + 縣市 + 鄉鎮市區 + 村里（有值才显示） + 路街段巷弄號 + 樓室` | 门牌、道路、县市、乡镇市区、邮编 | 仅接受中华邮政官方 3+3 六位；旧三位记录隔离，不补后三位 |
| 日本 JP | `〒邮编 + 都道府県 + 市区町村 + 町名 + 丁目番地号 + 建物/部屋` | 番地、道路/町名、都道府县、市区町村、町/区、邮编 | `123-4567` 或 7 位 |
| 韩国 KR | 道路名：`시/도 + 시/군/구 + 도로명 + 건물번호`；地番：`시/도 + 시/군/구 + 읍/면/동 + 번지 + 단지명` | 源道路名或地番、行政层级、小区名、邮编；不补造栋/室号 | 5 位 |
| 新加坡 SG | `门牌 + 道路 + 建筑 + #楼层-室 + Singapore + 邮编` | 门牌、道路、邮编 | 6 位 |

| 加拿大 CA | `门牌 道路, 单元, 城市, 省 邮编` | 门牌、道路、城市、省、邮编 | `A1A 1A1` |
| 墨西哥 MX | `道路 门牌, Colonia, 市镇, 州, 邮编` | 门牌、道路、Colonia、市镇、州、邮编 | 5 位 |

| 德国 DE | `道路 门牌, 邮编 城市` | 门牌、道路、城市、邮编 | 5 位 |
| 法国 FR | `门牌 道路, 邮编 城市` | 门牌、道路、城市、邮编 | 5 位 |
| 意大利 IT | `道路 门牌, CAP 城市 省代码` | 门牌、道路、城市、省、省代码、CAP | 5 位 CAP |
| 西班牙 ES | `道路 门牌, 邮编 城市, 省` | 门牌、道路、城市、省、邮编 | 5 位 |
